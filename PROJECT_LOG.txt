### PHASE 3 — Browser Launch Config Fix (Brave Browser)

**Problem:**
VS Code debug launcher was using `"type": "chrome"` with no executable path.
Google Chrome was not installed → error: "Unable to find an installation of the browser."

**Fix applied in `.vscode/launch.json`:**
```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "chrome",
      "request": "launch",
      "name": "Open index.html",
      "file": "${workspaceFolder}/index.html",
      "url": "file://${workspaceFolder}/index.html",
      "runtimeExecutable": "/Applications/Brave Browser.app/Contents/MacOS/Brave Browser",
      "runtimeArgs": [
        "--no-first-run",
        "--no-default-browser-check",
        "${workspaceFolder}/index.html"
      ]
    }
  ]
}
```

**Root cause of blank tab (second bug):**
No `file:` target was passed — Brave opened its default new tab.
Fixed by adding `file`, `url`, and `runtimeArgs` with the HTML path.
